Casual Challenge API

Prepare, review and start a new Season.

Admin token required

Everything here runs against /admin/v1/.... Get a token on the server, in /opt/casual-challenge-application: 

java -cp build/libs/casual-challenge-application-0.0.1-SNAPSHOT.jar -Dloader.main=gg.casualchallenge.application.CliTools org.springframework.boot.loader.launch.PropertiesLauncher generate-admin-jwt <your_name>

<your_name> = author of the season migrations, same style as the existing ones: raoul_zander, janik_nissen. No spaces, no colons. Valid for a year and not revocable on its own --> keep it safe.

Signed in as - the author of the season migrations, and preparedBy / committedBy in the report.

Add the new season as top most row. End Date = end of the current season + 10 weeks [what the API picks anyway]. "Neu spielbare Sets" and "Set Code Updates" come out of the draft, no need to look them up.

Prepare a season first.

Leave it all empty on the day the season starts. Defaults: start = today (UTC), end = current season + 10 weeks, prices = the 70 days before the start, staples = MtgGoldfish.

A future start date needs an earlier price window end, MTGJSON only has prices up to today. MtgGoldfish blocked or down? MTGTop8 counts main deck only, numbers differ a bit --> say so in the announcement. Or upload the two ban files, same format as /legacy/season/##/bans.json.

  1. Reading AllPrintings.json
  2. Reading AllPrices.json
  3. Reading the meta shares
  4. Calculating budget points and assembling the draft
  5. Storing the season draft

This takes a few minutes, depending on the server's line: ~200 MB of MTGJSON, a minute of scraping (deliberately slow, they don't like bots), half a minute of calculating. Cancelling only bites between steps.
