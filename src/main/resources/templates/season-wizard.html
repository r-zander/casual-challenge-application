    Remove a season

    Allows to undo committing the last season.
    Only works before the migrations have ever run.
    What it does exactly:

    • Removes the season entry
    • Removes the season card data
    • Roles back all renames and oracle id remaps
    • Sets the previous season back to its previous end date, so it's the active season again
    • (Optional) Closes the GitHub Pull Request
    The migrations of this season went to GitHub. The branch goes with the season, and that closes the pull request.
    Takes a few seconds: the card season data, the cards, the renames and the card cache on top.
    Season is gone. Season ends again. Reload the page before the next run.
